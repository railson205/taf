
=========================================
INSTRUÇÕES PARA EXPORTAR E IMPORTAR BANCO DE DADOS MYSQL (XAMPP)
=========================================

📍 LOCAL PADRÃO DO MYSQL NO XAMPP:
    C:\xampp\mysql\bin

=========================================
🔹 EXPORTAR (GERAR BACKUP)
=========================================

1️⃣ Abra o Prompt de Comando (cmd) do Windows.

2️⃣ Vá até a pasta do MySQL do XAMPP:
    cd C:\xampp\mysql\bin

3️⃣ Execute o comando abaixo (ajuste o nome do banco e o local de saída):
    mysqldump -u root -p NOME_DO_BANCO > "C:\caminho\para\backup.sql"

   ➜ Exemplo:
    mysqldump -u root -p taf_db > "C:\backups\taf_backup.sql"

4️⃣ Quando solicitado, digite a senha do usuário MySQL (deixe em branco se não houver senha).

✅ O arquivo .sql conterá todos os comandos para recriar o banco com seus dados.


=========================================
🔹 IMPORTAR (RESTAURAR BACKUP)
=========================================

1️⃣ Copie o arquivo backup.sql para um local fácil (ex: C:\backups).

2️⃣ Abra o Prompt de Comando e vá até a pasta do MySQL:
    cd C:\xampp\mysql\bin

3️⃣ Crie o banco de dados (caso ainda não exista):
    mysql -u root -p -e "CREATE DATABASE NOME_DO_BANCO;"

4️⃣ Importe o arquivo de backup:
    mysql -u root -p NOME_DO_BANCO < "C:\backups\backup.sql"

5️⃣ Digite a senha (se houver).

✅ O banco de dados será recriado com todas as tabelas e dados.


=========================================
🔹 OPCIONAL: USANDO O PHPMYADMIN
=========================================

👉 EXPORTAR:
    1. Acesse: http://localhost/phpmyadmin
    2. Selecione o banco de dados desejado.
    3. Clique na aba “Exportar”.
    4. Escolha o formato “SQL” e clique em “Executar”.
    5. O arquivo será baixado (.sql).

👉 IMPORTAR:
    1. Acesse: http://localhost/phpmyadmin
    2. Crie um novo banco (ou selecione um existente).
    3. Clique na aba “Importar”.
    4. Escolha o arquivo .sql e clique em “Executar”.

✅ Pronto! Seu banco foi restaurado com sucesso.

=========================================
💡 DICAS:
- Sempre mantenha backups regulares antes de alterações.
- Evite acentos ou espaços em nomes de bancos e arquivos.
- O XAMPP precisa estar com o serviço MySQL ativo para os comandos funcionarem.
